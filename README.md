# 🧮 Advanced Calculator (Dart)

## 📌 Overview

This is a **console-based calculator** built using **Dart**.
The project includes a wide range of mathematical operations, from basic arithmetic to more advanced functions.

It was developed as part of my journey in learning programming and improving my problem-solving skills.

---

## 🚀 Features

### 🔢 Basic Operations

* Addition
* Subtraction
* Multiplication
* Division (with zero handling)

### 📊 Advanced Operations

* Power calculation
* Factorial
* Fibonacci sequence
* Prime number check
* Even or Odd check
* Positive / Negative / Zero check

### 📈 Other Utilities

* Maximum of 3 numbers
* Minimum of 3 numbers
* Average of 3 numbers

### 📐 Geometry Calculations

* Square (Area & Perimeter)
* Rectangle (Area & Perimeter)
* Triangle (Area using Heron's formula & Perimeter)

## ▶️ How to Run

1. Make sure you have Dart installed.
2. Clone the repository:

```bash
git clone https://github.com/your-username/calculator_project.git
```

3. Navigate to the project folder:

```bash
cd calculator_project
```

4. Run the program:

```bash
dart run
```
